03 / DEVELOPMENT GOVERNANCE

Software Engineering Methodology

01. Strict 3-Tier Layered Architecture

The frontend never touches the database directly. Flow: Frontend → Axios Interceptor → REST API (/api/v1) → Controllers → Services → Prisma ORM → SQLite / PostgreSQL.

02. Automated Integration & E2E Testing

Every critical lifecycle state transition is verified by automated integration scripts: Registration → Login → Ad Creation (Pending) → Admin Moderation (Approved) → Filter Search → Favorites → Polling Chat.

03. Defensive Security & Integrity

Password salting with bcrypt (10 rounds), dual-token JWT rotation (15m access, 7d refresh), HTTP security headers with Helmet, and CORS restricted to client origin.

04. Unified Monorepo DX

Single-command setup with npm run setup (installs packages, pushes Prisma schema, and seeds 24 listings) and npm run dev using concurrently.

04 / ARCHITECTURAL OVERVIEW

System Architecture (Overview)

1

Presentation Tier (Next.js 14 on Port 3000)

App Router with dynamic pages: Home, Filtered Listings, Vehicle Detail, Compare, Sell, My Listings, Chat, Admin.

2

REST API Gateway (/api/v1 on Port 4000)

Express routing, Helmet headers, CORS policies, rate limiters, and Multer multipart vehicle photo uploads.

3

Controllers & Validation Middleware

Zod request validation schemas, JWT Bearer authentication guards, requireAdmin middleware, and centralized error handler.

4

Service & Persistence Tier (Prisma + SQLite/Postgres)

Type-safe queries, relation mapping, multi-column search indexes, and cascade deletion integrity.

05 / CORE FUNCTIONALITY

AutoMarket Core Features

🔍 Vehicle Search & Filters

Multi-attribute filter sidebar (Car/Bike, Brand, Price slider, Year, Fuel, Transmission, Condition), sorting, and pagination.

⚖️ 3-Vehicle Comparison

Side-by-side technical specs comparison table for up to 3 cars/bikes highlighting price and specification differences.

💰 EMI Loan Calculator

Interactive monthly installment calculator adjusting loan amount, interest rate, and tenure with total interest breakdown.

💬 In-App Buyer-Seller Chat

Two-pane inbox bound to specific vehicle listings with 5-second polling updates and unread message tracking.

📸 Photo Gallery & Post Ad

Multi-image vehicle photo upload with client preview, local disk storage via Multer, and 'Mark as Sold' toggle.

🛡️ Admin Moderation Queue

Approval/rejection queue for pending vehicles, user ban controls, ad report reviews, and real-time platform statistics.

💬
PHASE 04

Deal & Mark Sold
