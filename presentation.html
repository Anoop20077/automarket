03 / DEVELOPMENT GOVERNANCE

Methodology & Layered Design

01. Strict 3-Tier Decoupling

The frontend never touches the database. All interactions flow strictly across a REST boundary: Client → Axios Interceptors → Express Routes → Zod Middleware → Services → Prisma ORM → SQLite/PostgreSQL.

02. Automated Integration & E2E Testing

Every critical lifecycle state transition is verified with automated test suites: Registration → Login → Ad Creation (Pending) → Admin Moderation (Approved) → Filter Search → Favorites → Polling Chat.

03. Defensive Architecture & Security

Password salting with bcrypt (10 rounds), dual-token JWT rotation (15m access, 7d refresh), HTTP security headers with Helmet, and CORS restricted to client origin.

04. Unified Monorepo DX

Single-command setup with npm run setup (installs packages, pushes Prisma schema, and seeds 24 listings) and npm run dev using concurrently.

04 / ARCHITECTURAL OVERVIEW

System Architecture Overview

1

Presentation Tier (Next.js 14)

Responsive App Router, Client Components, ThemeContext, CompareContext, Axios token interceptors.

2

REST API Gateway (/api/v1)

Express routing, Helmet security, CORS policy, rate limiting, and Multer multipart local image uploads.

3

Controllers & Middleware

Zod payload schema validation, JWT auth guard, requireAdmin role verification, and centralized error handling.

4

Service & Persistence Tier (Prisma + SQLite/Postgres)

Type-safe queries, relation mapping, multi-field search indexes, and cascade deletion integrity.

Live client-side monthly payment calculation adjusting loan amount, interest rate, and tenure.

Listing approval/rejection workflow, user ban controls, report resolution, and platform stats.
